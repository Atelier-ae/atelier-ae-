ATELIER AE — STARTER PROTOTYPE

Files:
- index.html: homepage and demo application modal
- style.css: responsive black/white visual design with lime accent and hover motion
- app.js: demo interactions

This is a static visual prototype. It does not include real registration, authentication, database storage, user approval, payment processing, referral attribution or live commissions.

To preview: open index.html in a browser.
To publish: create a new GitHub repository and upload these three files to its root, then enable GitHub Pages in repository Settings > Pages.
